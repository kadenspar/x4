About
X4: Foundations Database and Utilities

An unofficial companion app for X4: Foundations. The current Android build targets X4 9.00 data and includes the station calculator, fleet builder, and reference pages for ships, equipment, modules, wares, factions and races.

Current data coverage
  • 63 wares
  • 325 station modules
  • 234 processed ships, with 250 effective app records after retained legacy/NPC entries
  • 542 processed hardware equipment records, with 617 effective app records after retained/special entries
  • Current missiles, drones and consumables used by the fleet builder
Data sources and references

The X4 9.00 dataset is generated from the 9.0-Empire extraction in slepher/x4-station-calculator, pinned to commit cb43e7fbbd2b64f173c8f127483f5f767ac11e07. The importer also uses the extracted raw 9.0-Empire X4 assets in that pinned source for prices, production recipes and macro statistics.

  • Processed X4 9.00 reference data
  • Extracted raw 9.0-Empire assets
  • X4 9.00 data audit and known limits
